## 三句话版本

1. **一个项目一个仓库，从第一天就用 git。** 代码、文档、决定都在里面，有历史可查。
2. **每个文件夹一份 README，写给人也写给 AI。** 信息不靠人记，AI 也能接着干。
3. **先分清能不能公开，再动手。** 敏感材料放私有空间，推送前有自动检查。

## 给 AI 的说明

- 这个文件夹是公开的。案例只写做法和公开的数字，不写内部讨论、产品细节或对人的评价（规则见 [05_privacy.md](05_privacy.md)）。
- 案例里的数字来自仓库的实际记录（git 历史、测试结果）；更新时重新查，不要估算。

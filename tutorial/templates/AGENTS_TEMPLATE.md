## 约定

- 先读根目录和相关文件夹的 README.md，再动手。
- 一次只做一件事；每个改动都要有测试或对照来证明。
- 提交说明：`类型: 做了什么`（feat / fix / docs / test / chore），下面写为什么。
- 改了文件夹里的东西，同步更新它的 README（更新记录、给 AI 的说明）。
- 数字、人名、日期来自原始文件或运行结果，不要估算或猜。

# templates：可直接复制的模板

> 新项目第一天用。复制后把【】换成自己的内容。

| 状态 | 负责人 | 最后更新 |
|---|---|---|
| 第一版 | Eden Huang | 2026-11-07 |

## 里面有什么

| 文件 | 复制到 | 用途 |
|---|---|---|
| [README_TEMPLATE.md](README_TEMPLATE.md) | 每个文件夹的 `README.md` | 统一的文件夹说明 |
| [AGENTS_TEMPLATE.md](AGENTS_TEMPLATE.md) | 根目录 `AGENTS.md` | 给 AI 编程工具的总说明 |
| [gitignore_template.txt](gitignore_template.txt) | 根目录 `.gitignore` | 私有、数据、结果、密钥不进 git |
| [PR_TEMPLATE.md](PR_TEMPLATE.md) | 合并请求的描述 | 改了什么、怎么验证、要谁看 |

## 给 AI 的说明

- 模板里不放任何具体项目的内容；本仓库的实际例子是根目录的 `AGENTS.md` 和各文件夹的 README。

# head：头部图谱可视化

> 头部解剖体素图谱和三维可视化脚本，准备作为下一个仿真预设，复算上期“到达灰质约 1%–2%”的结论。

## 里面有什么

| 文件 | 说明 |
|---|---|
| `fullhead_atlas.mat` | 头部体素图谱（USC atlas，变量 `USC_atlas`）：头皮、颅骨、灰质、白质等编号，330 KB |
| `D3D.m` | 读取图谱并画三维等值面 |

三维网页 `head_atlas_3d.html`（25 MB）和参考论文在本地 `references/head/`，见 [references/README.md](../../../references/README.md)。

## 怎么用

MATLAB 里进入本文件夹，运行 `D3D`。

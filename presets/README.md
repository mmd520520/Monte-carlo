# presets：参数预设

> 每个 YAML 文件是一套完整的模拟设置：几何、各组织光学参数（带出处）、光源、运行参数。改参数只改这里，不改代码。

## 里面有什么

| 文件 | 内容 | 单位 |
|---|---|---|
| `skin_500nm.yaml` | 皮肤血管，500 nm，来自 `legacy/matlab/2demo` | mm |
| `knee_980nm.yaml` | 膝关节，980 nm，来自 `legacy/matlab/5demo` | cm（载入时换算成 mm） |

## 写法约定

- `length_unit` 写明本文件长度单位（mm 或 cm）；吸收、散射系数用对应的倒数单位。
- 散射写 `musp`（约化散射系数，文献常用）或 `mus`，二选一。
- 每种组织必须写 `source`：文献、DOI 或“假设”。没有出处的数字不能进预设。
- 有疑问的地方写进 `notes`，界面上会显示。

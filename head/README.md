## 里面有什么

| 文件 | 说明 |
|---|---|
| `fullhead_atlas.mat` | 头部体素图谱（USC atlas）：头皮、颅骨、灰质、白质等编号 |
| `D3D.m` | 读取图谱并画三维等值面 |
| `head_atlas_3d.html` | 预渲染的三维网页，25 MB，将移到共享盘 |
| `Improving model-based functional near-infrared spectroscopy ….pdf` | 参考论文，将移到共享盘 |

## 怎么用

MATLAB 里进入本文件夹，运行 `D3D`。

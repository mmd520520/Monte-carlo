# 案例：Muse 头带的个性化体验是怎么搭起来的

> 一句话：Muse 卖的不是“脑电头带”，而是一个“戴上 → 实时听到自己状态 → 看到进步 → 被教练带着练”的闭环。硬件只是入口，体验由“传感 → 指标 → 反馈 → 长期个性化 → 证据”五层叠起来。除了没有光照干预，这和我们想做的脑环几乎一样，值得逐层拆开学。

| 项目 | 内容 |
|---|---|
| 公司 | InteraXon Inc.，加拿大多伦多 |
| 定位 | 官网写明：“a general wellness product, not a medical device”（健康消费品，不是医疗器械） |
| 产品 | **Muse S Athena**（2025 年 3 月上市，主打专注、心智耐力、睡眠，$474.99）；**Muse 2**（入门款，冥想，$249.99） |
| Athena 的传感器 | 脑电（EEG）、近红外（fNIRS，测前额叶血氧）、光电心率和血氧、加速度计和陀螺仪（评测报道；官网产品页本次未能打开核对） |

## 2. 一次训练是怎么进行的

1. **戴上、配对**：App 里配对头带；评测说配对“快而简单”，信号质量取决于贴合。
2. **选训练**：心智（Mind）、心率（Heart）、身体（Body）、呼吸（Breath）、计时；Athena 分成三类：Clarity（脑电专注）、Strength（近红外，练“心智耐力”）、Recovery（脑电放松）。
3. **实时反馈**：
   - 心智训练：背景声音像天气，**越平静声音越安静**，状态好时出现**鸟叫**。
   - Strength：画面里一只**猫头鹰**，越专注飞得越快、越远。
4. **训练后报告**：脑电各频段（γ、β、α、θ、δ）分解；近红外的脑血氧可以在训练中实时看。

**设计要点**：把看不见的生理信号翻译成**声音和画面**，用户不用看数字也知道“我现在对不对”。

## 3. 长期个性化

| 机制 | 怎么做 |
|---|---|
| 个人基线 | 认知表现分数在“几次训练后”建立基线，之后和自己比 |
| 分数 | Alpha Peak（α 峰频，联系专注和处理速度）、Brain Recharge（α 功率，作为恢复指标）、Brain Age（脑电 + 认知测验，和真实年龄比；首次免费） |
| 目标和计划 | 每周目标、训练后报告、可选的练习计划（Practice Plan） |
| AI 教练 | Enso：Premium 里“主动教练、唤醒并适应你” |
| 内容 | 500+ 节引导课程；可以把反馈叠加到其他音频 App 上 |

**设计要点**：先测出“你是谁”（基线），再让每次训练都和自己比，最后由教练把“下一步练什么”说出来。

## 4. 睡眠：同一个头带的第二个场景

- **睡眠分期**：用脑电 + 心率 + 呼吸 + 动作 + 脑血氧；官网引用的研究（Lanthier 等，*SLEEP Advances* 2025）与临床多导睡眠图一致率 **88–96%**，Kappa **0.76**，“和两位人工判读员之间的一致性相当”。
- **深睡增强**（Deep Sleep Boost）：检测到慢波睡眠时，精确定时播放粉红噪声。
- **智能唤醒**（Smart Wakeup）、**助眠音频**（声音在睡着后淡出、醒来时淡入）。

**设计要点**：一旦有了可靠的“状态检测”，就能在对的时间做对的事（播放、淡出、唤醒）——这就是“闭环”。

## 5. 证据和信任

| 证据 | 数字（官网和研究页说法） |
|---|---|
| 睡眠分期与多导睡眠图一致 | 88–96%，Kappa 0.76（Lanthier 2025） |
| 医护人员职业倦怠（Mayo Clinic，n = 40，26 周） | 倦怠降低 54% |
| 睡眠质量（Western University 等，2021） | PSQI 比对照改善 20% |
| 研究使用 | NASA、IBM、MIT、Yale、Harvard、多伦多大学等 |

官网同时强调“不是医疗器械”。**设计要点**：消费品也在用研究证据建立信任，但宣称范围卡在“健康”而不是“治疗”。

## 6. 用户怎么说（App Store 评分 4.3，约 1,500 条）

| 好评 | 差评 |
|---|---|
| 没有老师也能量化冥想进步 | **不能导出数据**（最常见的抱怨） |
| 睡眠洞察帮人找到影响深睡和 REM 的因素 | 睡眠图太粗（按小时显示分期） |
| 头带质量好，连接稳定 | 部分功能要订阅；声音反馈有时让人分心；夜里会移位 |

## 7. 让体验成立的研发底座

```
传感（脑电、近红外、心率血氧、动作）
  → 信号处理（去伪迹、贴合检测）
  → 指标（平静度、α 峰频、脑血氧、睡眠分期）+ 验证研究
  → 反馈设计（声音、画面、时机）
  → 长期个性化（基线、分数、目标、AI 教练）
  → 商业（设备 + 订阅）
```

每一层都要研发支撑；用户只感受到最上面那层。

## 8. 对我们的启示

我们的脑环（公司官网公开介绍）：可穿戴经颅光生物调控，低能量近红外，Gamma / Alpha 双模式，内置脑电、心率、血氧、红外温度传感器，App 和 AI 个性化方案。

| Muse 有的 | 我们一样需要 | 我们多出来的 |
|---|---|---|
| 传感 → 指标 → 反馈 → 个性化 | 同样的五层 | **光照干预**：闭环从“告诉你状态”变成“根据状态调整照射” |
| 近红外测脑血氧 | 近红外传感 | 同一束近红外光既是治疗也可能是测量，深度和剂量都要算清楚 |
| 宣称停在“健康” | 宣称边界要先定 | 干预涉及医疗器械监管，证据要求更高 |
| 验证研究建信任 | 验证研究 | 剂量—效应的证据 |

**蒙特卡洛仿真在哪里帮忙**：

- **剂量**：多少光能到达皮层？头发、肤色、颅骨厚度影响多大？（需要头部模型）
- **测量深度**：近红外传感器的读数主要来自多深？（需要探测器统计）

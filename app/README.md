## 怎么用

```bash
uv run streamlit run app/streamlit_app.py
```

浏览器打开 http://localhost:8501。左侧选模型和参数，点「开始模拟」。第一次运行要编译内核，约 10 秒；之后同样设置的结果会缓存。

| 标签页 | 内容 |
|---|---|
| 组织模型 | 截面图、各组织光学参数和出处、注意事项 |
| 光分布 | 对数色标的光注量截面（可移动 y 截面）、中心轴深度曲线 |
| 剂量 | 指定深度的中心轴和圆面平均累计光注量（需要设定功率） |
| 导出 | 结果 `.npz`、本次完整参数 `.json`、剂量表 `.csv` |

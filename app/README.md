# app：交互界面（科普 + 产品）

> 浏览器里的两部分：**科普**（方法从哪来、仿真、验证）给研发和想学的人；**产品**（从研发到产品）给管理团队和产品同事，自己点一点、试一试。中英双语。

| 状态 | 负责人 | 最后更新 |
|---|---|---|
| 可用（本地运行），中英双语，两部分共 7 页 | 马孟帝、Eden Huang | 2026-11-07 |

## 怎么用

```bash
uv run streamlit run app/streamlit_app.py
```

浏览器打开 http://localhost:8501。左侧选页面；右上角「中文 | EN」切换语言，切换只改文字、不重新计算。链接带 `?lang=en` 直接打开英文版。

| 部分 | 页面 | 内容 |
|---|---|---|
| 科普 | 论文与前沿 | 我们复现的经典方法（MCML、Jacques 教程、mcxyz、加倍法、MCX）和相关前沿研究，每篇一句话 + 原文链接 + 在本工具里对应什么 |
| | 仿真 | 两个模型（皮肤血管 500 nm、膝关节 980 nm）：组织截面、光分布、剂量、导出 |
| | 验证 | 任意均匀平板，本引擎和加倍法对比，给出差值 ÷ 标准误差 |
| 产品 | 从研发到产品 | 我们的产品线（官网公开介绍）、从研发到产品的五层 |
| | 案例：Muse | Muse 个性化体验拆解，加一次可体验的训练（随机数模拟的示意） |
| | 脑环闭环设计 | 选场景、传感器、反馈、光照方式，画出闭环，列出要研发回答的问题，可下载 |
| | 康复激光 | 功率、光斑、时间 → 表面功率密度、表面能量密度、皮下各深度剂量（膝关节模型） |

## 文件

| 位置 | 是什么 |
|---|---|
| `streamlit_app.py` | 入口：语言切换、页面导航 |
| `views/` | 每页一个文件 |
| `content/` | 长文字：每段中英各一份（`*.zh.md`、`*.en.md`）；`papers.yaml` 是论文清单 |
| `common.py` | 共用：当前语言、读内容文件、读私有笔记、缓存的仿真 |

**内部笔记**：“产品”部分的页面会读 `project/private/app/` 里的 Markdown（例如激光和医学事务的协作案例）。这个文件夹不进 git，所以只有拿到私有资料的电脑上才显示；其他人看到的是“内部内容在私有空间”。

## 给 AI 的说明

- 页面只负责布局；计算放 `mcsim/`，画图放 `mcsim/plotting.py`，平板对照放 `mcsim/reference.py`。
- 短的界面文字放 `mcsim/i18n.py` 的 `TEXT`；长文字放 `content/`，中英各一份。不要在页面代码里直接写中文或英文段落。
- 这里是公开仓库：产品部分只用官网公开的信息和公开案例；内部讨论放 `project/private/app/`，用 `common.private_content()` 读。
- 示意数据（例如 Muse 训练）必须在页面上写明是模拟的。
- 下拉框按语言分 key（`preset_zh`、`preset_en`），选中的值另存在 `preset`。
- 改界面后跑 `uv run pytest tests/test_app.py tests/test_i18n.py`。

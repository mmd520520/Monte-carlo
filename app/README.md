## 怎么用

```bash
uv run streamlit run app/streamlit_app.py
```

浏览器打开 http://localhost:8501。左侧选模型和参数，点「开始模拟」。第一次运行要编译内核，约 10 秒；之后同样设置的结果会缓存。

**语言**：右上角「中文 | EN」切换，切换只改文字，不重新计算。链接带 `?lang=en` 直接打开英文版，方便发给不看中文的同事。中文版里少数关键名词附英文（如 光注量率 fluence rate、体素 voxel），方便两套术语对照。

| 标签页 | 内容 |
|---|---|
| 组织模型 | 截面图、各组织光学参数和出处、注意事项 |
| 光分布 | 对数色标的光注量截面（可移动 y 截面）、中心轴深度曲线 |
| 剂量 | 指定深度的中心轴和圆面平均累计光注量（需要设定功率） |
| 导出 | 结果 `.npz`、本次完整参数 `.json`、剂量表 `.csv` |

## 给 AI 的说明

- 界面只负责布局；计算放 `mcsim/`，画图放 `mcsim/plotting.py`。
- 界面上的每一句话都放在 `mcsim/i18n.py` 的 `TEXT` 里，中英各一份；预设里的文字用 YAML 的 `*_en` 字段。不要在界面代码里直接写中文或英文。
- 下拉框按语言分 key（`preset_zh`、`preset_en`），选中的值另存在 `preset`；这是为了切换语言时选项文字能跟着变。
- 改界面后跑 `uv run pytest tests/test_app.py`。

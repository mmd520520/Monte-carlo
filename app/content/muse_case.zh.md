**Muse 卖的不是“脑电头带”，而是一个闭环**：戴上 → 实时听到自己的状态 → 看到进步 → 被教练带着练。硬件只是入口。

| 层 | Muse 怎么做（公开资料） |
|---|---|
| 传感 | Muse S Athena（2025）：脑电、近红外（前额叶血氧）、心率血氧、动作传感器 |
| 指标 | 平静度、α 峰频（Alpha Peak）、脑恢复（Brain Recharge）、脑龄（Brain Age）、睡眠分期 |
| 反馈 | 声音像天气：越平静越安静，状态好时有鸟叫；近红外训练里猫头鹰越专注飞得越远 |
| 个性化 | 几次训练后建立个人基线；每周目标、练习计划；AI 教练 Enso（订阅） |
| 睡眠闭环 | 检测到深睡时定时播放粉红噪声；智能唤醒；睡着后声音淡出 |
| 证据 | 睡眠分期与临床多导睡眠图一致 88–96%（Kappa 0.76）；官网写明“不是医疗器械” |
| 商业 | 设备 $249.99–474.99；订阅（官网 $49.99/年） |
| 用户抱怨 | 不能导出数据；部分功能要订阅；夜里头带会移位 |

**和我们的区别**：Muse 到“反馈给人”为止；我们的脑环多一步**光照干预**，闭环变成“测状态 → 调整光照 → 再测”。这一步需要剂量的科学依据，也带来医疗器械的监管要求。
